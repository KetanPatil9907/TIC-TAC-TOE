# 🎮 Tic-Tac-Toe Game

A simple, interactive, and responsive **Tic-Tac-Toe** game built using **HTML, CSS, and JavaScript**. This project demonstrates core web development concepts such as DOM manipulation, event handling, game logic, and responsive design.

---

## 🚀 Features

- 🎲 Two-player gameplay (Player X vs Player O)
- 🏆 Automatically detects the winner
- 🤝 Detects draw/tie games
- 🔄 Restart/New Game functionality
- 📱 Responsive design for desktop and mobile
- ⚡ Smooth and user-friendly interface

---

## 🛠️ Technologies Used

- **HTML5** – Structure of the game
- **CSS3** – Styling and responsive layout
- **JavaScript (ES6)** – Game logic and interactivity

## 🎮 How to Play

1. Open the game in your web browser.
2. Player **X** starts the game.
3. Players take turns clicking on empty cells.
4. The first player to get **three marks in a row, column, or diagonal wins**.
5. If all cells are filled and no player wins, the game ends in a **Draw**.
6. Click **Restart** or **New Game** to play again.
